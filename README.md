# からっと

温度計なしで天ぷらを揚げるブラウザゲーム。頼りになるのは、衣のしずくの沈み方と、泡の音だけ。
**遊ぶ：** https://krieafly8661.github.io/karatto-tempura/


## 遊び方

1. 火加減（弱火・中火・強火）を選ぶ。
2. 「衣を一滴」で油の温度を見る。
   - 底まで沈んでゆっくり浮く：まだぬるい（150℃台）
   - 途中まで沈んですぐ浮く：ちょうどいい（170〜180℃）
   - 沈まずに表面で散る：熱すぎる（180℃超）
3. ボタンを押しているあいだ衣をつけ、はなすと油に入る。長く押すほど衣が厚くなる。
4. 揚げ始めは泡が大きく、音が低い。泡が小さくなり、音が高く小さくなったら「引き上げる」。

5品を揚げると盛りつけと点数が出て、結果をXに投稿できます。結果には、入れたときの本当の油の温度も表示されます。

| 失敗 | 原因 |
| --- | --- |
| 外は真っ黒、中は生 | 油が熱すぎる |
| 油を吸ってしんなり | 油がぬるい・衣が厚い |
| 衣に花が咲いた | 高めの温度に、うすい衣で入れた（成功） |

操作：スペースキーで衣づけ・引き上げ、1/2/3で火加減、Dで衣を一滴。

## 動かし方

`index.html` を開くだけで遊べます。外部ライブラリは使っていません。音は Web Audio API で作っています。

## このゲームを作った理由

2026年10月下旬のXでは、だし巻き・オムライス・たこ焼きなど「料理の手順をそのまま遊ぶ」ゲームがいちばん多く流行していました。点数より「断面」や「焼き上がり」を見せ合う作りが共通点です。このゲームは、そこに「本物の見極め方（衣のしずく・泡の音）だけで判断する」という一手を足しています。
